# Book Notes — Trading Library Reference Archive

This directory preserves the structured knowledge extracted from the trading
book library that was previously stored in this project directory. The
original PDF/EPUB/MOBI files have been deleted (they were sourced from
piracy sites per their own filenames, and pirated PDFs are a real malware
vector) — these notes capture the facts, rules, formulas, and numbers that
were pulled from them for use in the TradeSight app (`../tradesight/`),
organized as reference material for future work.

These are summarized/paraphrased structured notes, not the books' text —
appropriate for citing sources and reusing facts, not for redistributing the
original works.
